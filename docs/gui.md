# PySide6 图片 GUI：原图、结果与统计

编号：JKB-010 · 历史验证：已实测 · 最近整理：2026-10-18

## 已实现
pt/engine模型选择、打开图片、置信度/IoU、后台推理、左右对比、当前类别数量、保存当前图片。
## 用户证据
2026-10-18照片显示TensorRT加载和person4/bus1、检测完成。
## 设计
QThread运算，信号回主线程；QImage.copy持有内存；QPixmap只在GUI线程创建；运行期间禁用输入，关闭前检查线程。
## 边界
历史图片版每次点击重新加载模型；单轮19.14ms不与预热5.74ms直接比较。保存功能有实现，用户未独立验收。
